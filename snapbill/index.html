SnapBill

영수증을 찍으면 AI가 읽어, 내 구글 시트와 캘린더에 자동으로 기록해 주는 가계부 앱

Google Play에서 받기 개인정보처리방침

SnapBill이란?

SnapBill은 스페이스 랩이 만든 영수증 가계부 앱입니다. 종이 영수증을 촬영하면 AI가 날짜, 상호, 금액, 카테고리를 읽어 기록하고, 원하는 경우 이용자 본인의 구글 시트와 구글 캘린더에도 남겨 지출을 한눈에 볼 수 있게 도와줍니다.

주요 기능

영수증 AI 판독

영수증을 촬영하거나 사진을 불러오면 AI가 날짜, 상호, 금액, 카테고리를 자동으로 읽어 줍니다. 읽은 내용은 저장하기 전에 직접 고칠 수 있습니다.

구글 시트에 기록

선택한 영수증을 내 구글 시트에 기록합니다. 새 시트를 만들거나 SnapBill로 만든 시트에 이어서 추가할 수 있고, 월별 탭과 종합 대시보드(차트)가 자동으로 만들어집니다. 앱의 리포트 화면에서 기록한 시트의 내용을 다시 불러와 볼 수도 있습니다.

구글 캘린더 일정

지출을 내 구글 캘린더에 일정으로 등록하고(선택 기능), 앱의 캘린더 화면에서 일정을 보고 추가·삭제할 수 있습니다. 내일 일정은 알림으로 알려 줍니다.

스캔 횟수

처음에는 무료 스캔 횟수가 제공되며, 광고를 시청하거나 유료 충전권을 구매해 횟수를 더할 수 있습니다.

구글 데이터 사용

SnapBill은 이용자가 구글 로그인 때 허용한 경우에만 아래 구글 권한을 사용하며, 표에 적은 목적으로만 사용합니다.

구글 권한 사용 목적 접근 범위
구글 시트
(spreadsheets)		 선택한 영수증 내역을 내 구글 시트에 기록하고, 앱의 리포트·월별·가져오기 화면에서 그 시트의 내용을 읽어 보여 줍니다. 이용자가 연결하거나 앱이 만든 시트에 한해 읽기·쓰기
구글 드라이브 — SnapBill이 만든 파일
(drive.file)		 SnapBill이 만든 시트의 목록을 보여 주어 이용자가 고를 수 있게 합니다. SnapBill이 만들었거나 이용자가 앱으로 연 파일만 해당. 이용자의 다른 파일에는 접근하지 않습니다.
구글 캘린더 일정
(calendar.events)		 지출 일정 등록(선택 기능), 앱의 캘린더 화면에서 일정 조회·추가·삭제, 내일 일정 알림 일정의 조회·등록·삭제만 합니다. 캘린더 자체의 생성·삭제·공유 설정은 하지 않습니다.
  • 구글 시트·캘린더 데이터는 이용자의 휴대폰과 구글 사이에서만 오가며, 운영자의 서버로 전송되거나 저장되지 않고 운영자는 열람하지 않습니다.
  • 구글 사용자 데이터를 광고에 사용하거나 판매·양도하지 않으며, 인공지능 모델의 개발·학습에도 사용하지 않습니다.
  • 구글 연동은 언제든지 구글 계정 설정 → 보안 → 타사 앱 연결에서 SnapBill을 삭제해 해제할 수 있습니다.

SnapBill의 Google API 데이터 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

자세한 내용은 개인정보처리방침의 9장 구글 사용자 데이터의 사용을 확인해 주세요.

개인정보 보호

영수증 기록은 기본적으로 이용자의 휴대폰에만 저장됩니다. 운영자의 서버(Google Firebase)에는 로그인, 스캔 횟수, 결제 확인에 필요한 최소한의 정보만 저장하며, 영수증 사진은 운영자 서버에 보관하지 않습니다. 앱의 설정에서 계정을 직접 삭제할 수 있습니다.
